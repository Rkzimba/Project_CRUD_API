# API de Gerenciamento de Produtos

API REST desenvolvida com **ASP.NET Core Minimal API**, **Entity Framework Core** e **SQLite**, permitindo o gerenciamento de produtos por meio de operações CRUD (criar, listar, atualizar e remover).

## Tecnologias

- .NET 10
- ASP.NET Core Minimal API
- Entity Framework Core
- SQLite

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Consulta por ID
- Atualização de produtos
- Exclusão de produtos
